# Room Helper

집 도면의 실제 축척과 배치 가능한 방 경계를 맞춘 뒤 가구를 2D로 배치해 보는 로컬 웹 앱입니다. 도면, 여러 축척 기준선, 측정선, 방 영역, 가구 목록과 배치는 `data/project.json`에 자동 저장됩니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:5173](http://localhost:5173)을 엽니다. `npm run dev`는 Vite 화면(`5173`)과 로컬 Express API(`8787`)를 함께 실행합니다.

## 사용 순서

1. 왼쪽에서 PNG/JPEG/WebP 평면도를 업로드합니다.
2. `축척 기준선 추가`를 누르고 도면에 표시된 치수선 양 끝을 클릭합니다.
3. 치수를 mm/cm/m 중 맞는 단위로 입력합니다. 가로와 세로 기준선을 각각 하나 이상, 가능하면 여러 개 등록합니다.
4. `도면의 다른 길이 재기`로 임의 구간이 실제 치수와 맞는지 확인합니다.
5. `새 배치 영역 그리기`에서 각 방의 실내측 모서리를 순서대로 선택합니다. 거실·주방처럼 열린 공간은 하나의 영역으로 그립니다.
6. `가구 추가하기`에서 이름과 가로·세로(cm)를 입력합니다.
7. 오른쪽 가구 카드를 중앙 캔버스로 드래그하거나 캔버스에서 배치된 가구를 이동합니다.
8. 가구는 어느 위치든 놓을 수 있습니다. 초록색은 정상 배치, 빨간색은 벽 밖·다른 방·다른 가구와 겹치는 상태이며 빨간 위치도 그대로 자동 저장됩니다.

기존 단일 축척 형식(`schemaVersion: 1`)의 JSON은 실행 시 다중 축척 형식(`schemaVersion: 2`)으로 자동 변환됩니다.

## 검증

```bash
npm run build
npm test
```

`npm start`는 production 클라이언트와 API를 `8787` 포트에서 함께 제공합니다. 처음 실행할 때는 다음처럼 빌드합니다.

```bash
npm run build
npm start
```

그 다음 [http://localhost:8787](http://localhost:8787)을 엽니다. 개발 시에는 Vite 화면과 빠른 갱신을 위해 `npm run dev`를 사용합니다.
